# Security policy

HONG AI Edge Cage is security-sensitive software and remains alpha until Windows WFP, macOS Seatbelt, fail-closed proxy, watchdog and recovery tests pass on the published support matrix.

Do not report suspected vulnerabilities in a public issue when the report contains an exploit, customer data, credentials, proxy endpoints or unpublished release details. Use GitHub's private vulnerability reporting for this repository after it is enabled by the repository owner.

Never include a license key, one-time token, signing key, release content key, proxy credential, OAuth token, cookie, customer IP or customer configuration in an issue, pull request, workflow log or screenshot.

Supported security fixes are published only from signed HONG AI release tags. Source commits and unsigned development artifacts are not customer releases.
