HONG AI CAGE｜官方桌面隔离安装包
2026-11-26

先完成第一步网络配置，再安装本包。安装前退出 Claude，保持 Clash 和远控运行。

Windows：双击 Windows-x64 文件夹里的 Setup.exe，确认正常的管理员授权。
Mac：双击 macOS-Universal 文件夹里的 .pkg；安装后从“应用程序”打开 HONG AI CAGE Desktop。

首次使用：
1. 确认官方 Claude Desktop 已安装，且已退出。
2. 按 01 说明生成并导入 clash-handoff.json。
3. 选择一个具体的工作文件夹，再点“启动 Claude 桌面版”。
4. 以后会保存交接配置和工作文件夹；每次启动仍重新核对最终出口。

这两个安装包运行已安装且签名有效的官方 Claude Desktop，不是网页外壳，不包含账号、代理密码或 Claude 本体。
不使用 VM、Lima、Debian 镜像，不预分配 30～100 GB。安装文件很小，隔离登录资料与缓存会随使用增长。
Windows 预留至少 5 GB，优先安装数据盘；自有沙箱设置缓存与软容量阈值，授权工作项目大小另计。

网络行为：
进程只允许访问本次会话的私有代理入口，入口再连接第一步提供的 Clash 端口。
入口失效、出口核验失败或工作台关闭时，停止本次会话，不主动切换 DIRECT。
Clash 的最终链路必须按 02 说明绑定专用入口，不能只凭 IP 查询结果判断整条链安全。
安装器不修改 Wi-Fi、TUN、系统 DNS、系统代理或路由，不重启电脑。

Windows 使用未修改、签名有效的 Sandboxie Classic 隔离核心。Mac 使用系统进程沙箱。
两端均提供独立登录数据；保留客户原有 Claude 登录资料，不以删除整机资料作为安装条件。
工作区中的代码与文档仍可交给 Claude 使用；不要把整个用户目录选为工作区。

验收范围：实际安装、原生界面、官方程序离线启动、子进程继承网络限制、代理停止后的阻断，以及卸载恢复。
本包尚未完成真实账号登录、真实业务、全部 MCP/扩展、Cowork 和系统集成验收。
Windows 允许在隔离区内试验本地 MCP/桌面扩展；Cowork/Code 额外虚拟环境关闭。Mac 的外部浏览器认证与系统代办能力须单独验收。
不要把“安装成功”当成“所有桌面功能已验收”，不能签发满分证书或承诺零泄漏。

Mac 安装包没有 Apple Developer 发布签名与公证。遇到系统拦截时按系统正常流程由操作者确认；不得关闭 Gatekeeper/SIP。
Windows 安装器本身暂无组织代码签名，内含的上游核心有原始有效签名。不得关闭 Defender。

本包不清除硬件指纹，不伪造系统身份，不对任意文件中的位置/IP 文本做自动加密或脱敏。
TLS 仍由官方应用使用；网络隔离不等同于识别所有工具输出中的敏感内容。
需要共享文件时先选择具体工作区并检查内容。
