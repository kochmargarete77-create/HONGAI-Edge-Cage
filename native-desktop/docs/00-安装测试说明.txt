HONG AI CAGE｜桌面隔离安装测试包 pilot.3

1. 退出旧 CAGE 和 Claude，保持 Clash、ToDesk 运行。
2. Windows 双击 Windows-x64 中的 Setup.exe；Mac 安装 macOS-Universal 中的 .pkg，从“应用程序”打开 CAGE。
3. 首次导入第一步的 clash-handoff.json，选择具体工作文件夹，再启动 Claude。
4. 配置保存后，以后双击 CAGE 直接启动，不需要重复选择代理或目录。
5. 设置、状态和停止操作在 Windows 托盘或 Mac 菜单栏的 CAGE 中。

关闭设置窗口只隐藏设置；“停止隔离会话”或“停止并退出”会关闭本次受控 Claude。
代理不可用或出口核验失败时停止会话，不切 DIRECT，不重置网络。

Windows 本版需要已注册且签名有效的官方 Claude x64 MSIX。首次从官方文件建立校验副本，额外占用通常约 1 GB；原安装与 WindowsApps 权限保持不变。
Mac 使用原有官方 Claude app，Apple 芯片与 Intel 共用通用包。
两个小安装包均不含账号、订阅、代理密码或 Claude 本体，不需要 VM、Lima 或 Debian 镜像。

这次已验证真实安装入口、官方桌面启动、保存配置后的再次启动、停止与卸载。
真实账号登录、聊天、完整 MCP/扩展、Cowork 及系统集成仍须单独验收。
Windows 副本不保留 MSIX 包身份，协议回调、通知和更新尤其需要复测。详见 05 文件。

安装包尚无 HONG AI 组织发布签名/Apple 公证，按系统正常流程由操作者确认；不得关闭 Defender、Gatekeeper 或 SIP。
本包不修改 Wi-Fi、TUN、系统 DNS、系统代理和路由，不要求重启。
始终从 CAGE 入口启动；原系统 Claude 图标不计入本工具的隔离声明。
