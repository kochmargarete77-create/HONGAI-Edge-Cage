HONG AI CAGE｜完整版桌面隔离

名称说明
pilot.4 是第 4 个试运行版本编号，不是 Power Light，也不表示完整版验收通过。
现版运行未经改写且签名有效的官方桌面程序，尚未完成下列全部功能。不得仅改文件名便作为完整版交付。

完整版目标
1. 官方桌面程序完整启动，独立登录与用户数据。
2. 本地 MCP、文件与工具调用、桌面扩展实际可用。
3. 登录回跳、快捷键、通知及所需系统集成可用。
4. 获准的桌面进程和工具流量保持指定出口，故障时停止联网。
5. 更新、停止、恢复、卸载与后台常驻可验证。
6. Windows 与 Mac 分开打包，安装依赖、说明、校验和记录完整。
7. 完整版包含 Cowork 适配，按客户实际用途、账号运行模式与网络验收结果启用；不要求所有客户无条件安装本地虚拟机。

本版已有证据
Windows 两组、Mac 四组独立测试机已验证安装、缺少官方程序时的引导安装、未登录启动、签名副本、已保存配置再次启动、所测网络边界和停止恢复。
Windows 的连续四版本轮换使用模拟源；Mac 的更新副本复用使用已测官方版本。这些结果不替代未知新版的兼容验证。

仍未达到完整版的项
Windows 当前禁用了 Code 与 Cowork。私有副本没有 MSIX 包身份，登录回跳、通知和依赖包身份的能力尚未验收。
Mac 当前禁止 Apple Events 与部分系统代理启动通道；任意系统集成不能默认视为可用。
两端的真实登录、本地 MCP、文件操作、桌面扩展和必要快捷键仍需实际功能验收。
独立登录目录必须核对实际文件访问和配置存储路径；只有 --user-data-dir 参数或进程存活，不能证明所有账号状态和扩展都已隔离。
HONG AI Windows 发布签名、Mac Developer ID 签名/公证尚缺。客户授权安装不能代替发布证书或 Apple 公证。
容量是软阈值巡检，不是文件系统硬配额；具体客户实体机和长期使用仍需记录结果。

开发与验证顺序
先补齐认证回调与身份连续性，再验证真实 MCP/文件/扩展；涉及沙箱外系统进程代执行的功能，必须先建立其网络边界。
不通过解除网络限制、改全局防火墙、启用虚拟机或重启客户电脑来冒充功能完成。
第一步仍为未登录的环境检测与整改；第二步的登录功能由客户本人交互验证，凭据不进入日志或智能体。
功能清单逐项有证据后才标记 FULL_DESKTOP_ACCEPTED。现版 fullDesktopAccepted=false。
