状态、隐私与恢复说明

配置仅保存在本机当前用户保护的存储中。工作台只监听 127.0.0.1，操作需要本次会话令牌，不提供第三方远程控制接口。

未登录安装检查与客户自行登录后的业务测试分别记录。正常使用期间不清 Cookie、应用标识或登录资料，不改写官方程序，不停用其他软件，不修改 TUN、DNS、路由、Wi-Fi 或防火墙。

卸载只恢复本组件明确修改的 MCP 配置，再将工作台目录改名保留。配置发生客户后续修改时停止，避免覆盖。官方 Claude、客户账号与项目资料保留。

本工作台的 HONG AI 发布签名、公证、完整环境模拟及真实账号业务验收须各自有证据，当前验证版不表示正式全部通过。
