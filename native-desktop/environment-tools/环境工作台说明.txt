HONG AI｜原生环境工作台
版本：0.1.0-environment-preview
适用：Windows x64；macOS Intel / Apple Silicon（Universal）

一、这是哪一部分

本包用于准备和诊断已配置好的客户电脑环境：识别官方 Claude 的安装身份、签名、版本和资料目录，保存工单配置，检查现有本机代理入口，并用正常方式打开官方桌面程序。
管理页面在本机浏览器内显示；真正使用的 Claude 仍是官方桌面程序。本包不内置 Claude 网页、不附带 Claude 安装文件或已登录账号，不修改官方程序或其更新链。

这是环境准备与诊断验证版。物理硬件模拟、官方客户端所有原生流量的系统级强制边界、真实账号功能和长期会话尚未因此验收通过。工作台入口回显通过，也不能替代第一步对真实目标程序的路由和故障行为验收。
HONG AI 的组织发布签名、Apple Developer ID 和公证状态见包内 VALIDATION.json。客户正常安装授权不能代替签名或公证；不要关闭操作系统安全检查。

二、安装前

1. 完整解压 ZIP 到本机一个普通文件夹。不要在压缩文件预览窗口内直接运行。
2. 由服务人员先完成第一步宿主环境评估，核实客户现有 Clash 链式规则和最终出口。暂未完成时可以打开工作台盘点，但不要勾选已经验收。
3. 准备三项工单数据：本机 Clash HTTP / Mixed 入口、批准的最终公网 IPv4、目标时区。例如入口可以是 http://127.0.0.1:17896；这个端口仅为格式示例，不代表客户已启用。
4. 使用客户日常登录的 Windows / Mac 用户。不要使用 SYSTEM、root，或换成另一位管理员的用户上下文。

工作台本身为自包含原生程序，不需要另外安装 Go、Node、Docker、Linux、虚拟机或驱动。客户自行选用的 MCP 服务可能有独立运行时要求，需按该工具的说明准备；不能把任意第三方工具的依赖视为已经随本包安装。

三、第一次使用

Windows：双击“安装环境工作台.cmd”。
Mac：双击“安装环境工作台.command”。

首次操作系统可能要求确认来源、允许打开本机程序或访问当前用户的密钥存储。请由客户按正常系统提示确认；如果被安全策略阻止，保留提示交给服务人员核查，不运行关闭 Gatekeeper、清除 quarantine、绕过 SmartScreen 或修改安全策略的命令。

工作台会打开本机管理页面，只监听 127.0.0.1。页面需要本次会话令牌；不要转发地址给第三方，也不要把带令牌的地址放进截图或交付日志。

在“一次性环境配置”中填入工单批准值，确认第一步完成后保存。配置由 Windows 当前用户 DPAPI 或 Mac 当前用户 Keychain / AES-GCM 保护；不会导入订阅、代理密码或登录凭据，也不会改动 Clash、系统代理、TUN、DNS、路由、防火墙、Wi-Fi 或系统时间。

四、获取与打开 Claude

1. 已有官方桌面程序时，先看“官方签名已核验”和实际版本；不要复制成另一份程序，不要在 WindowsApps 中直接运行受保护 EXE。
2. 没有官方程序时，点“官网获取 / 更新 Claude”，从官网按正常流程安装。返回后刷新状态；尚未完成安装时可继续等待识别。
3. 点“检查批准入口”。工作台只通过填写的本机 HTTP / Mixed 代理进行三次 HTTPS 回显，不使用环境代理或 DIRECT 回退。回显与工单不一致时不得当成通过，也不会自动用实测值改写工单。
4. 点“打开官方 Claude”。若第一步确认、官方签名、工单时区或入口检查不符合要求，会停止本次启动并显示待处理状态；不会擅自修改系统配置来“修成通过”。
5. 账号、密码、验证码、SSO 等由客户本人完成。第一步未登录检查与登录后的真实业务示范分开记录。

五、后续日常使用

工作台安装后会在自己的安装目录生成日常入口：
Windows：HONGAI-Environment.cmd
Mac：HONGAI-Environment.command

默认安装目录：
Windows：优先 E:\HONGAI-Environment，其次 D:\HONGAI-Environment；没有这两个盘时使用当前用户应用数据目录下的 HONGAI-Environment。
Mac：当前用户 ~/Library/Application Support/HONGAI-Environment。

日常入口执行 environment use：保存配置满足条件时直接请求打开官方桌面，正常使用无需重填代理参数。条件不足时回到管理页面处理。配置或安装源文件夹删除后，已安装的工作台运行文件仍在自己的稳定目录中。
需要修改配置时，打开管理页面的“配置与修改”，或使用环境命令 environment open。

工作台不会周期性清理客户合法会话，不随机更换应用身份，不重建客户 Profile。官方 Claude 正常更新后需重新核验安装身份、版本和原有资料路径；工作台不把“发现新版本”直接当成新版本全部功能已经通过。

六、关闭、卸载与恢复

“关闭工作台服务”只关闭本工作台，不关闭 Claude、Clash、ToDesk 或其他程序。默认工作台会话最长 120 分钟；关闭后可从日常入口重新打开。

需要卸载时，先关闭工作台服务。在完整包的目录打开终端，执行：
Windows：HONGAI-Environment.exe environment uninstall --root "实际安装目录"
Mac：./hongai-environment environment uninstall --root "实际安装目录"

卸载不删除官方 Claude、客户账号、Claude 资料、工程、系统网络或其他软件。它检查工作台归属，恢复本工作台登记的 MCP 配置（如有），随后将自己的整个目录改名为“原目录.removed-随机标识”保留。需要恢复时保留该目录和当前系统用户，不要自行删除密钥或恢复文件。
如客户在部署后改过 MCP 配置，恢复会先停止，防止覆盖客户的新改动；请让服务人员比较后处理。独立安装在其他数据根目录中的工具隐私组件需按各自回执单独恢复，不能假定本工作台卸载已处理所有独立组件。

七、给客户本地智能体的最短执行提示

“这是 HONG AI 原生环境工作台的准备与诊断验证包。先核对 VALIDATION.json 和 CHECKSUMS-SHA256.txt；在客户正常系统用户下运行本平台的安装入口。不要修改 Clash 或系统网络，不清理登录资料，不升级权限、重启或停用远控。由服务人员提供工单批准的本机代理入口、最终 IPv4 和时区，先完成第一步评估再勾选确认。不得把 HTTPS 回显、进程存活、未登录启动或本机管理界面当成完整环境模拟、全流量边界和账号功能验收通过。遇到异常只保存错误代码和脱敏操作记录，由客户本人完成所有账号登录。”

八、证据与隐私

VALIDATION.json 绑定源码提交、CI、平台测试范围、二进制 SHA-256 和当前未验收项。
CHECKSUMS-SHA256.txt 可用于核对包内文件；独立的 ZIP.sha256 可核对外层压缩包。哈希一致说明文件匹配，不等于签名、公证或官方认证。
工作台日志记录操作类别与结果代码，不包含聊天、文件正文、代理密码或客户 Token。回传时仅发送脱敏说明和必要证据，不发送配置密文、密钥存储、账号资料或带令牌的本机页面地址。
