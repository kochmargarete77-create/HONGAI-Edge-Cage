HONG AI 环境工作台｜准备与诊断验证版

这是什么
这是 Windows 每用户 MSI 安装包。管理界面在浏览器本地页面中显示；经核验启动的是原样的官方 Claude Desktop，不是 claude.ai 网页外壳。本组件不包含 Claude 安装包、账号、Cookie、代理订阅或出口密码。
目前提供官方安装识别、本地配置保存、指定代理入口诊断、脱敏日志及官方桌面启动；不具备完整硬件模拟或官方桌面全部流量的系统级出口闸门，不承诺账号安全或完整环境验收。组织签名尚未提供，Windows 可能提示未知发布者；不要关闭系统安全或绕过组织策略。

安装
1. 用将来实际使用的 Windows 用户登录。先安装工作台；无需预装或登录 Claude。工作台发现缺少官方程序时，由客户通过官网正常下载安装，然后刷新核验。
2. 双击 HONGAI-Environment-Workbench-版本-x64.msi，完成普通安装。仅安装当前用户，不要求管理员权限；组织策略仍可能要求管理员批准。
3. 桌面和开始菜单均出现 HONG AI Environment。第一次双击后，在工作台填写已经配好的本机 Clash HTTP/Mixed 入口、批准的最终出口和对应时区，并完成第一步环境验收确认。
4. 本组件不修改 TUN、系统代理、DNS、网卡、全局防火墙、时区、硬件身份，也不清除 Claude 登录资料。原代理工具继续独立运行。

日常使用
桌面入口固定不变。后续双击会复用已保存配置；入口状态、官方包身份和所需环境条件满足时请求打开官方桌面。缺少配置或检查不通过时进入工作台说明原因，不会自动切直连。诊断请求本身只通过指定入口，但这不代表本组件已经强制接管官方桌面的所有流量。
官方 Claude 自行更新；本工作台重新识别已安装且签名有效的官方包，通过系统应用模型启动 MSIX，不直接运行 WindowsApps 内的受保护 EXE。未知身份或验证失败时要求重新检查，不强行启动。
本组件没有独立常驻 Windows 服务，不安装驱动。工作台运行期间有其自己的本地管理进程和限时会话；退出管理页面不等于退出官方 Claude。

目录与升级
安装程序：%LOCALAPPDATA%\Programs\HONG AI Environment Workbench
私有配置与版本化运行时：%LOCALAPPDATA%\HONGAI-Environment
这两个目录职责分开。安装程序升级使用严格递增的三段版本号，保持 UpgradeCode；旧产品在安装事务开始后移除，失败时可由 Windows Installer 回滚。发布前必须实测不同版本 EXE 哈希确实被替换，不能只看安装成功提示。不要使用 REINSTALLMODE 强制覆盖个人配置。本安装器不设置 REINSTALLMODE，升级走 Major Upgrade。
私有根为组件专用目录，继承权限会收紧。客户工程、文档和额外项目不得混放其中；后加入文件的继承 ACL 可能随组件维护变化。请把工作项目保存在原工程目录。
MSI 升级不删除个人配置或干扰已经从私有目录运行的工作台。升级前用工作台停止按钮结束旧管理服务；只关闭浏览器标签页不够。然后从固定桌面入口打开，才能切换到新版运行时。已有密文无法解密会保留原文件并拒绝覆盖，请导出诊断单后恢复。

卸载与保留
Windows 设置 → 应用 → 已安装的应用 → HONG AI Environment Workbench (Preview) → 卸载。
MSI 卸载移除安装文件和自身快捷方式、安装标记，保留私有配置、版本化运行时及诊断记录；正在从私有运行时运行的工作台也不会被强杀，可自行关闭或等待会话到期。官方 Claude、账号、Clash、系统网络和其他程序不受安装器清理。
如要另外移除工作台私有数据，先关闭工作台，使用独立保留的发行 EXE 执行：
  hongai-environment.exe environment uninstall --root "%LOCALAPPDATA%\HONGAI-Environment"
此命令有所有权校验，遇到未知文件、活动会话或路径异常会拒绝删除。不要通过递归删除跳过保护；把未识别文件交给服务人员复核。本说明不等于授权清理 Claude 或客户工程。

验收边界
MSI 构建成功只证明打包完成。安装、真实不同 payload 升级、拒绝降级、卸载保留数据与运行中工作台不受影响，必须在独立 Windows CI/测试机获得结果；没有结果的项标记 NOT_RUN。Mac 使用独立安装路线，Windows 结果不代表 Mac 通过。完整环境 customerReady 仍为 false。
