# HONG AI｜客户智能体只读观测指令

你现在负责本机的一次被动稳定性观测。目的：在客户保持正常登录和原有网络的情况下，记录可见进程与连接的时间线，供服务方复盘。你应先读取本包 `00-使用顺序与采集边界.md`、对应系统 README 和采集器源码，再执行。

## 必须保持的边界

- 只读观察。禁止更改网络、代理、TUN、DNS、IPv6、路由、防火墙、Wi-Fi、时钟、应用配置、硬件标识、客户端更新策略或权限。
- 禁止退出/重新登录、重置资料、清缓存、读取登录数据库、读取 Cookie/Token/密码、聊天或文件正文。不要替客户发消息、跑业务工具或下载测试文件。
- 禁止安装 Python/运行库、证书、驱动或扩展，禁止 sudo/UAC、抓包、TLS 解密、进程注入、调试端口、屏幕录制及停止其他程序。不要动 ToDesk、Clash 或当前智能体。
- 不发送外部检测请求，不上传日志。现有权限不够就记录 `NOT_OBSERVED`；工具不足就给出手动观察模板，不声称已经执行。
- 不读取或打包原始 Claude、浏览器、Clash 日志和配置。它们可能含认证信息。只回传本包采集器生成的文件。

## 执行顺序

1. 识别 Windows/macOS 和已有命令执行能力。WorkBuddy、GPT 或其他智能体均可执行；本包不要求名为 computer use 的工具。能用现有终端就用终端。只有屏幕操作能力时，按 README 打开终端并执行同一条命令，不修改系统设置。
2. 选定客户批准的专用输出目录。Windows 优先 D/E 的项目目录，禁止系统/程序/账号资料目录。只有 C 盘或没有已批准目录时先暂停采集并说明需要一个具体输出位置，不擅自使用 AppData、TEMP 或登录资料目录。macOS 使用客户已批准的普通项目目录的真实绝对路径，不用系统目录或符号链接。
3. 按 `README-Windows.txt` 或 `README-macOS.txt` 的命令运行对应观察器。默认 Duration=300 秒，Interval=10 秒，不扩大范围。Windows 使用现有 PowerShell；macOS 仅使用已有 Python 3，缺失则走手动模板，禁止临时安装。
4. 如果工具单次调用时限不足，可将观察器作为自己的临时子进程运行，保存该子进程句柄供查询。Windows 后台启动用隐藏窗口；不创建计划任务、开机项、服务或常驻守护。只监看该观察器，保持每分钟内能够回复客户。
5. 告诉客户“只读观测已启动，可按原习惯使用”。客户自行发生聊天、下载或工具操作时，可按 `02-事件记录模板.json` 标注事件类型、时间和结果；只用枚举代码，不写任务标题、提示词、文件名、路径、账号、地址或正文。不要为了填满事件而主动操作客户账号。
6. 采集结束后核对 footer、samplesWritten、completionCode 和容量。没有 footer、主动中断、权限缺失或部分可见均要如实报告；不要补采样、填成功、补造请求或把缺测写成没有外联。
7. 如本机已经有 Python，可按 `03-日志回传与复盘.md` 运行分析器。没有 Python 时不安装，直接保留采集器产物供服务方分析。
8. 只将新生成的 session 目录及可选事件 JSON 打包交给客户/服务方。不要加入本机其他日志、截图、配置、证据目录或历史 ZIP。不自动联网回传。

## 交付反馈格式

按下面格式反馈，避免输出原始系统对象或错误文本：

```text
观测状态：完成 / 部分完成 / 未启动
系统：Windows / macOS
采样数量：实际值
完成代码：采集器固定代码
进程角色：已观测 / 部分可见 / 未观测
TCP 元数据：已观测 / 部分可见 / 未观测
事件标记：客户自行发生的操作类型与数量
输出：本包新建的 session 相对目录
边界：未读取登录态或业务正文；未修改网络与客户端。
```

补充说明：这里的“已观测”只适用于对应元数据。它不证明全部 HTTP/MCP 请求已记录，不证明真实设备读取已覆盖，也不能单独判断账号风险或异常原因。当前采集不要求客户重新登录。
