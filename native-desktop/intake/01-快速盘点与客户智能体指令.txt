HONG AI｜快速设备盘点与执行分流
版本：2026.11.27-1

用途
本模块只收集必要的设备元数据并选择后续流程。不登录、不联网测试、不安装、不删缓存、不改网络，也不授予权限。
输出不是评分、验收或防封承诺。UNVERIFIED_CANDIDATE 仅表示未命中这份分流表的阻断项。

给客户智能体的首条消息
你是本次 HONG AI 服务的现场执行助手。先运行本模块的只读盘点，读取 JSON 的 findings；按 severity 区分产品缺项、设备阻断、待核查和提示。
产品缺项交回服务方，不要通过修改客户系统、解除网络限制或清登录态来弥补。再进入现有第一步完整检测、整改、复测流程；第一步不登录 Claude。
未知值保留为未知。历史目录存在只表示可能有历史状态，不证明账号异常或封禁，不读取登录凭据，也不自动删除。
远控进程存在不证明远控通道在线；变更前由操作员确认仍可交互及本地恢复入口可用。
传闻也必须登记和检查，使用“预防规则”处理；依据、适用版本、触发迹象、反例及副作用均需记录。不要把传闻写成官方已公布的封号条件。

Windows
双击 00-只读设备盘点-Windows.cmd 可在窗口查看结果；默认只盘点，不安装。
智能体应使用系统原生 64 位 Windows PowerShell 5.1 执行 Check-Device-Windows.ps1，避免 PowerShell 7 的 Appx 模块差异。
参数 -Target 可取 NetworkAssessment / DesktopPilot / FullDesktop；默认 NetworkAssessment。
参数 -CoworkMode 可取 NotRequired / Unknown / Cloud / LocalVM；默认 NotRequired，不需要 Cowork 时不要强装虚拟机。
输出只到标准输出。若需留档，由智能体保存到本次服务授权的数据盘目录，并先检查目标文件不存在。
未匹配到 MSIX 不等于机器没有其他安装形态；快速盘点未扫描所有磁盘或任意 Win32 安装目录。

Mac
双击 Check-Device-Mac.command；命令等价为 bash Check-Device-Mac.command NetworkAssessment NotRequired。
只用系统自带 bash、JXA 与 Foundation，不需要安装 Node、Python、Homebrew 或开发工具。
区分 Apple Silicon 硬件与 Rosetta 下运行的进程，按硬件选择原生或 Universal 包。
快速盘点不请求辅助功能、屏幕录制、完全磁盘访问或自动化授权，不使用 sudo。后续确需某项权限时，再只申请该项。
管理配置、可用内存、TUN 路由及非常规安装位置未完整检查时会保留限制说明，不默认为干净。

流程
1. 填一次服务编号、目标功能、已有前置节点组、最终出口和工作区；凭据单独保管，不写入回传日志。
2. 运行只读盘点，先分产品缺项、设备兼容、代理链路、认证会话、第三方服务状态，避免混修。
3. 修复时一次只改一个获准范围；先离线校验候选配置，再检查受影响项，不每改一行就跑全量网站。
4. 最终交付仍按原第一步要求全量复测；检测窗口最多同时保留 2–3 个测试标签。
5. 第二步独立验证实际需要的桌面功能、更新和断联行为。网络高分不能替代真实登录、MCP、扩展或 Cowork 验收。

分流规则的边界
10 GB 可用磁盘和 1 GB 当前空闲内存是本模块的保守资源复核提示，不是官方风控阈值，也不是完整运行容量承诺。
多个 TUN 候选只是排查线索，不自动删除网卡、不自动关闭代理。目录存在、进程存在、代理 IP 回显和实际服务连接路径应分别核验。
现有 FULL-DESKTOP-REQUIREMENTS.json 仍为完整版能力依据；当前 fullDesktopAccepted=false。本工具不会提升产品能力或改变评分权重。
