# 下一层适配契约

本地模型和 provider 已实现；厂商测试客户端连接器尚未接入。授权前提按用户说明记录，不要求提交证书、私钥、账号或联系人。

| 观察面 | 当前实现 | 目标客户端接入所需内容 |
|---|---|---|
| network | 合成网络快照，无真实请求 | 测试网络信息采集器接口及各 helper 的接入范围 |
| regional | 规范化语言、地区和 IANA 时区 | 客户端实际格式化、时间和区域读取的测试接缝 |
| platform | 受约束的系统/架构描述 | 专用测试版本的原生系统信息 provider |
| hardware | 稳定的合成设备、CPU、内存元数据 | 厂商设备采集模块接口；真实指令执行能力另行验证 |
| rendering | 合成图形元数据 | renderer 采集接口及实际图形执行测试；名称不代表渲染能力 |
| state | 合成资料修订与状态描述 | 测试客户端存储及测试认证回调契约，不使用真实账号凭据 |
| tools | 合成工具能力和上下文 | 实际 MCP、扩展、子进程的接入清单与读回接口 |

每个连接器必须声明：厂商、测试构建标识、平台/架构、版本、协议、已覆盖读取路径、未覆盖路径和证据来源。不得通过关闭正式验签、重签官方程序或静默回退本地 mock 来填补缺失。

当前运行结果只允许 `LOCAL_SIMULATOR_READBACK`。进入 `VENDOR_ADAPTER_VERIFIED` 必须有对应测试客户端完成真实协议连接和读回；进入 `TARGET_CLIENT_VERIFIED` 必须有指定客户端版本、实际进程及工具的读回证据。模型输入、样例输出与真实读回不能混为一谈。

需要补充的技术信息是 SDK/接口名称、专用测试客户端入口或接入文档。所有生产服务、实际登录和目标进程接入操作保持未执行。
