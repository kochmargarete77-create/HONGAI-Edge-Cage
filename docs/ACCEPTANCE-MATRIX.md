# HONG AI Edge Cage 验收矩阵

正式交付默认要求综合分不低于 90，且下列硬门槛全部通过。分数不能抵消硬门槛。

| EC-01 | 官方 Claude Code 固定版本 | 包锁、版本输出、校验记录 | 无 | 拒绝启动 |
| EC-02 | 独立状态与宿主历史隔离 | 独立 HOME、USERPROFILE、CLAUDE_CONFIG_DIR | 首次环境无旧会话 | 拒绝交付 |

| EC-04 | 本地 Clash 代理可用 | TCP 监听探测 | Clash 运行界面 | 拒绝启动 |
| EC-05 | 唯一最终出口 | 连续三次出口一致且等于工单 IP | 外部出口页复核 | 拒绝启动 |

## 必做负向测试

1. 关闭最终出口，只保留前置节点：Claude 必须断网。
2. 临时把允许域名解析到私网或回环：请求必须被拒绝。
3. 尝试读取宿主 SSH、浏览器、Clash 和其他项目目录：必须失败。
4. 尝试写入工作区和状态目录之外：必须失败。
5. 运行时改变 Clash 路由导致出口变化：看门狗必须终止会话。
6. 重启、崩溃和断网后恢复：不得出现 WFP、DNS 或路由残留导致宿主断网。

## 与 HONG AI 网络评分的关系

Edge Cage 验收是产品安全门槛；HONG AI 跨境网络环境严格评分是外部网络质量门槛。两者都通过才允许正式交付。外部 20 站或后续扩展站点的评分不替代本矩阵，Edge Cage 的沙箱测试也不替代浏览器 DNS、IPv6、WebRTC 和信誉证据。
