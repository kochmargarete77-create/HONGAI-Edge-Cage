# HONG AI CAGE Lite 0.2.1

This branch carries the audited lightweight Electron workbench as a split source envelope. GitHub Actions reconstructs the source, runs the complete test suite, builds one native macOS package per CPU architecture, verifies Electron security fuses, performs a cold-start smoke test, creates a DMG, mounts it, and verifies the complete application bundle.

The public repository contains no customer proxy, subscription, credential, cookie, token, code-signing private key, or customer account data.

Version 0.2.1 adds fail-closed HTTPS/WSS request admission, three-pass stable startup verification, delayed-Clash automatic recovery, a bounded credential-free runtime audit, and a regression fix that keeps unavailable external proxy probes in a failed state.
